📋 Descripción

Sistema empresarial desarrollado con Django para la gestión de un catálogo de items. Este proyecto forma parte del curso de **Desarrollo de Aplicaciones Empresariales** y sirve como base para las siguientes sesiones del curso.

🚀 Características

- Gestión de items (CRUD)
- Panel de administración personalizado
- Búsqueda interactiva con JavaScript
- Diseño responsive con Bootstrap 5
- API REST (opcional)
- Interfaz moderna y amigable
